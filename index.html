手机遥控使用说明

一、HC-08 接线（与 ST-Link / USB-TTL 共存）

HC-08 引脚接 STM32说明
VCC3.3V 或 5V按模块丝印供电，与车上共地
GNDGND必须共地
TXDPA10（RX）模块发 → 单片机收
RXDPA9（TX）单片机发 → 模块收

HC-08 出厂 9600 / 8N1，与固件一致，无需任何 AT 配置。固件协议零改动，与 USB-TTL 控制完全等价。

二、手机怎么打开本页（必须安全上下文）

  1. 局域网联调（最快）：电脑双击「启动手机联调.cmd」，手机连同一 WiFi，在手机 Chrome 打开 http://电脑IP:8765/mobile.html。首次需在手机 Chrome 地址栏输入 chrome://flags/#unsafely-treat-insecure-origin-as-secure，填入该网址并启用，重启浏览器。
  2. USB 转发（免白名单）：电脑执行 adb reverse tcp:8765 tcp:8765，手机访问 http://localhost:8765/mobile.html。
  3. GitHub Pages（正式发布）：把本文件上传到 GitHub 仓库并开启 Pages，手机访问 https 地址，无需任何白名单。

iPhone 的 Safari 不支持 Web 蓝牙，本页在 iOS 上只能用「演示」模式。iPhone 用户请改用支持 BLE 的串口 App（如 nRF Connect 手动发 HEX），或考虑 ESP32 方案。

三、操作流程

  1. 小车上电，HC-08 LED 闪烁（表示未连接）。
  2. 点「连接 HC-08」→ 在弹出的选择器里选 HC-08（或你改过名字的模块）。
  3. 点「测试通信」，收到 OK 表示链路通。
  4. 点方向 / 机构按钮执行一次动作；观察到动作完成后再点「动作已完成，继续」。

四、指令协议（与桌面控制台一致）

功能帧（HEX）回传

每帧 6 字节 FF 01 01 01 CMD FE；舵机调试帧 FF AA 舵机号 角度 00 FE；自定义行程帧 FF BB 方向 脉冲低 脉冲高 FE（需 2026-10-24 后固件，控制页"行程模式"面板使用）。

五、常见问题

  • 搜不到 HC-08：模块未上电、已被其他手机连着（HC-08 单连接），或距离太远。
  • 连接后发指令没反应：先点「测试通信」看是否收到 OK；检查 TXD/RXD 是否接反；若模块波特率被人改过，用 AT 指令恢复 9600。
  • 发送失败 / 频繁断开：离近一点、重新连接；手机省电策略会杀后台蓝牙，控制时保持本页在前台（页面会自动申请屏幕常亮）。
  • 回传是什么意思：ForWard 等只表示「指令已识别」，不代表动作完成；机构动作完全没有回传。

固件没有急停指令。断开蓝牙或关闭页面都不会停止已开始的动作。
